# 실모델 시험 범위 — 아직 미실행

2.0 preview의 오프라인 검사 이후 확인할 항목이다. 업무 모델이 아닌 별도 Revit 2024 시험 프로젝트와 복사한 CAD 파일을 사용한다. 설치에는 모든 Revit 창 종료가 필요하며, 아래 내용은 자동 실행 스크립트가 아니다.

## 1. 요청·문서·복구

두 시험 문서를 연다. 첫 문서에서 얻은 토큰을 두 번째 문서가 활성 상태일 때 제출하면 변경 없이 거절되어야 한다. 문서 수정 후 이전 수정번호로 제출해도 거절되어야 한다. 레벨 생성 요청의 ID와 인자를 그대로 두 번 보내면 레벨은 한 번만 생기고 같은 결과를 반환해야 한다.

Revit이 다른 명령을 처리하여 요청이 대기 중일 때 시간초과 또는 서버 중지를 발생시키면 해당 요청은 `cancelled_before_execution`이고 나중에도 실행되지 않아야 한다. 이미 실행 중일 때의 시간초과는 `running`으로 구분해야 한다. 서버 재시작 전에 연결된 클라이언트의 지연 요청은 새 세션에서 실행되지 않아야 한다. 완료된 변경 요청은 재시작 후 같은 ID로 결과만 반환해야 한다. 강제 종료 시험은 미저장 업무 데이터가 없는 독립 시험 환경에서만 수행한다.

## 2. CAD 초기 배치

층별 건축·구조·설비 DWG/DXF와 명확한 단위·기준점을 준비한다. 기존 레벨 배치와 새 레벨/평면뷰 생성 각각에서 표고·축척·회전·앵커 위치를 도면 치수와 대조한다. 진북이 회전한 프로젝트도 별도 검사한다. 같은 계획 재적용 시 중복 링크가 없어야 한다. 도면 내용·기준점·기존 링크를 바꾸면 명시적으로 재검토를 요구해야 한다. 마지막 파일이 잘못된 배치는 앞서 만든 링크·레벨·뷰도 되돌려야 한다.

복구본·상세도·`2-5층`·`2 및 3층`·층 범위가 있는 폴더·다층 DWG는 자동 단일 층 배치가 차단되어야 한다. 파일명과 실제 도면 내용의 일치는 사람이 확인한다. DWG 내부 층 구역 자동 인식은 이 버전의 시험 대상이 아니라 미구현 기능이다.

## 3. 간섭과 3D 뷰

겹치는 요소 한 쌍, 떨어진 요소, 정상 커넥터 접속, 이동/회전된 링크, 같은 링크의 복수 인스턴스, 미로드 링크를 포함한 작은 고정 시험 범위를 사용한다. API 계산값과 Revit에서 직접 확인한 겹침을 대조한다. 한도를 낮춘 검사는 `partial`로 보고해야 한다. 누락을 무간섭으로 처리하면 실패다.

검사 뒤 요소를 이동하면 뷰 생성 시 다시 검사해야 한다. 3D 뷰의 섹션박스·카메라·호스트 색상·링크 표시를 실제로 확인한다. 링크 내부 개별 요소 강조는 보장 범위가 아니다. 생성 실패 시 이번에 생성한 검토 뷰 전체가 롤백되는지 확인한다.

## 4. 에너지·시스템 해석

기지의 작은 시험 건물에서 에너지 설정의 GUI 값과 MCP 조회값·수정값·단위를 비교한다. 기존 해석모델의 재생성/실패 롤백, 원본 요소 참조, gbXML의 단위·공간·면 내용을 확인한다. 검증된 EPW/OSW와 설치된 해석 엔진으로 요청·보고서·취소 흐름을 검사한다. `completed`만으로 성공 판정하지 않고 보고서/로그를 확인한다. 실패한 요청이 남긴 보고서와 출력 파일도 조사한다.

## 통과 기록

문서/파일 식별, Revit 빌드, 도구 인자, 요청 ID, 수정 전후 요소 ID, 실제 화면/기하 결과, 누락, 소요시간을 기록한다. 중복·문서 전환·중지·롤백부터 통과시키고 도메인 기능을 확대한다. 동일 시험을 기존 버전과 반복 측정하기 전까지 더 빠르거나 더 안정적이라는 비교 수치를 발표하지 않는다.
